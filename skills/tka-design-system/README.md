# TKA Design System Agent Skill

Reusable agent instructions for creating TKA Egypt branded assets and design deliverables in Arabic or English.

## Use
1. Give your agent access to this repository or a current checkout.
2. Install/copy the complete skills/tka-design-system/ directory into the agent's supported Skills directory.
3. Ensure the agent can read canonical design rules and access the actual logo files.
4. Ask for the deliverable in natural language, for example:

   Create a Facebook banner in Arabic for a free beginner course on using AI to manage daily tasks and business. Sessions are every Saturday at 6:00 PM. Emphasize practical projects and the TKA-Egypt certificate claim. Follow the official TKA design system and use the correct logo from the repository.

5. Require the agent to return the actual exported file and a PASS/PARTIAL/FAIL report.

## Important
- This skill supplies instructions; it does not itself generate images or provide a design tool.
- Agent Skills installation paths and support vary by agent. Follow the selected agent's current documentation.
- Do not copy only this README. The skill file and repository design assets/rules are required.
- Use a current repository revision, not a stale local copy.
- Logo paths must be discovered from the repository; do not hard-code an unverified path.
