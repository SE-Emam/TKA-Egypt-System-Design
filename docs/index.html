Design System

One visual contract for every TKA Egypt product.

This repository is the source of truth for TKA Egypt brand tokens, Panda CSS recipes, visual-quality rules, and accessibility gates. Precise, not ornamental — calm enterprise structure, editorial typography, Arabic-first.

Principles

  • Semantic tokens only — no raw colors, spacing, or type values in product code.
  • Borders and whitespace define structure; decoration never carries meaning.
  • Every change passes automated gates: tests, contrast math, static anti-slop checks, typecheck, and Panda codegen.
  • RTL is a layout decision from the start, not a final patch.
Full documentation lives in the repository: github.com/SE-Emam/TKA-Egypt-System-Design
